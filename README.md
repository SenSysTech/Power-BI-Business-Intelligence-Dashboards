# Power-BI-Business-Intelligence-Dashboards
1- Spinning Production Dashboard
2- Cash Recovery from Clients Dashboard
3- Debtors Aging (Accounts Receivable Aging) Dashboard

Technology: Microsoft Power BI
Database: Oracle Database – Production Server
Data Integration: Live data connectivity and synchronization with the Oracle production database.
1. Spinning Production Dashboard
The Spinning Production Dashboard has been developed in Microsoft Power BI to provide comprehensive monitoring and analysis of spinning production activities. It enables management to monitor total production, analyze production trends, and evaluate output based on yarn quality, selection, and production periods.
The dashboard is integrated with the Oracle production database server, ensuring that production information is synchronized with the latest available production data.
Key Features and Functionalities:
1. Total Bags Produced: Displays the overall quantity of bags produced, providing a quick overview of spinning production performance.
2. Year-Wise Production Filtering: Allows users to filter production information by year, with additional date-based selection capabilities.
3. Bags by Quality: Provides a graphical analysis of production quantities across different yarn qualities, helping management evaluate the production distribution.
4. Monthly Production Analysis: Displays month-wise production trends, enabling management to compare production output throughout the year.
5. Year-Wise Quality Distribution: Illustrates the percentage and quantity of production for different yarn qualities through graphical representation.
6. Selection-Wise Production Analysis: Provides detailed production quantities based on individual yarn selections and specifications.
7. Quality-Wise Production Details: Displays a detailed listing of yarn qualities along with their respective production quantities.
8. Unit-Wise Filtering: Enables users to view production information for the selected business unit.
Business Benefits:
•	Provides centralized visibility into spinning production.
•	Helps management monitor production performance and trends.
•	Supports quality-wise and selection-wise production analysis.
•	Facilitates production planning and performance evaluation.
•	Reduces dependency on manually prepared production reports.

2. Cash Recovery from Clients Dashboard
The Cash Recovery from Clients Dashboard has been developed in Microsoft Power BI to provide comprehensive financial reporting and monitoring of cash collections received from customers and clients.
The dashboard presents customer-wise, monthly, daily, and year-wise cash recovery information, enabling management and finance departments to monitor collection performance and analyze incoming cash flows.
It is connected to the Oracle production database server, ensuring that cash recovery information is synchronized with the latest available financial transactions.
Key Features and Functionalities:
1. Total Cash Recovery (PKR): Displays the overall amount recovered from customers, providing an immediate overview of total cash collections.
2. Year-Wise Recovery Filtering: Allows users to select specific financial or calendar years to analyze cash recovery transactions for the selected period.
3. Customer-Wise Cash Recovery: Provides a graphical representation of cash collections from individual customers, identifying major contributors to total recoveries.
4. Monthly Recovery Analysis: Displays month-wise cash recovery trends, enabling management to compare collection performance across different months.
5. Customer-Wise Recovery Details: Provides a detailed listing of customers along with their respective recovered amounts.
6. Daily Recovery Analysis: Presents customer-wise recovery information through graphical representation, supporting detailed analysis of collection transactions.
7. Unit-Wise Filtering: Allows users to filter and analyze cash recovery information for individual business units, including COMP.1 and COMP.2.
Business Benefits:
•	Provides real-time visibility into cash recovery performance.
•	Helps finance teams monitor customer payment collections.
•	Identifies major customers contributing to cash inflows.
•	Supports monthly and daily recovery performance analysis.
•	Improves financial monitoring and cash flow management.
•	Helps management evaluate customer payment and recovery trends.

3. Debtors Aging (Accounts Receivable Aging) Dashboard
The Debtors Aging Dashboard has been developed in Microsoft Power BI to monitor outstanding customer receivables and analyze unpaid balances according to their respective aging periods.
The dashboard provides a consolidated view of total outstanding receivables, aging-wise distribution, and customer-wise outstanding balances. It enables management and finance departments to identify overdue amounts, monitor outstanding customer accounts, and prioritize recovery activities.
The dashboard is integrated with the Oracle production database server, ensuring that receivables information is synchronized with the latest available financial data.
Key Features and Functionalities:
1. Total Receivables (PKR): Displays the overall outstanding debtor balance, providing a consolidated overview of accounts receivable.
2. Receivables Aging Analysis: Categorizes outstanding customer balances into different aging periods:
•	Above 90 Days
•	01–15 Days
•	31–60 Days
•	61–90 Days
3. Aging Distribution Analysis: Presents the percentage and amount of outstanding receivables across different aging categories through graphical representations.
4. Period-Wise Receivables Analysis: Displays outstanding balances for each aging category, enabling management to identify the concentration of overdue receivables.
5. Customer-Wise Outstanding Balances: Provides a detailed listing of customer accounts along with their respective outstanding amounts.
6. Unit-Wise Filtering: Enables users to filter receivables information by business unit, including COMP.1 and COMP.2.
7. Graphical Receivables Comparison: Provides comparative charts of outstanding balances across aging periods, helping management identify high-value overdue accounts.
Business Benefits:
•	Provides consolidated visibility into outstanding customer receivables.
•	Identifies long-overdue customer balances.
•	Helps prioritize debt recovery and collection activities.
•	Supports credit control and receivables monitoring.
•	Improves working capital and cash flow management.
•	Enables management to identify customers with significant outstanding balances.
•	Facilitates better financial planning and collection decisions.

4. Technical Architecture and Data Integration
All three dashboards have been developed using Microsoft Power BI and integrated with the organization's Oracle Database Production Server.
The dashboards use production database information to generate interactive graphical reports and analytical insights. Data synchronization ensures that users can access the latest available information without relying on manually prepared Excel reports.
Technical Implementation:
Component	Technology / Description
BI & Visualization	Microsoft Power BI
Database	Oracle Database
Data Source	Oracle Production Server
Data Integration	Direct database connectivity
Data Synchronization	Real-time data synchronization
Reporting	Interactive charts, tables and graphical reports
Filtering	Year-wise, unit-wise, customer-wise and period-wise
Currency Reporting	PKR
5. Overall Business Impact
The implementation of these three Power BI dashboards provides management with an integrated Business Intelligence reporting solution covering production operations and financial performance.
The dashboards improve organizational reporting capabilities by transforming Oracle database transactions into meaningful visual insights.
Key organizational benefits include:
•	Centralized Reporting: Consolidated access to production and financial information.
•	Real-Time Visibility: Access to the latest available production and financial data.
•	Improved Decision-Making: Supports management decisions through interactive analytical reports.
•	Operational Monitoring: Facilitates production performance and quality monitoring.
•	Financial Control: Strengthens monitoring of cash recoveries and outstanding receivables.
•	Reporting Efficiency: Reduces manual reporting efforts and improves information accessibility.
•	Management Insights: Enables management to identify trends, evaluate performance, and take timely corrective actions.
